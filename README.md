# MoveIt Galaxy configuration and support

Public support pages and remote settings for `com.moveit.app.gx` on Galaxy Store.

- Site: https://metosapps.github.io/moveit-galaxy-config/
- Privacy: https://metosapps.github.io/moveit-galaxy-config/privacy.html
- Terms: https://metosapps.github.io/moveit-galaxy-config/terms.html
- Support: https://metosapps.github.io/moveit-galaxy-config/help.html
- Config: https://metosapps.github.io/moveit-galaxy-config/config.json

Advertising starts disabled. Do not enable production advertising until this exact app is live,
its app-specific AdMob identifiers and consent settings are configured, and the owner explicitly
authorizes activation. An APK update is required to change the manifest AdMob App ID.

Increment `revision` for every configuration change. The client rejects the wrong package/store,
invalid types and unsafe limits. Advertising approval expires and must be renewed within seven
days. Remote configuration cannot grant Pro, add permissions, or install executable code.

`galaxy_release_available` must remain false until the release is actually available in Galaxy
Store. Never force an update to an unavailable store binary.
